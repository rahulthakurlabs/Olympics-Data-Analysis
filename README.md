# 🏅 Olympics Data Analysis & Visualization

An Excel-based data analysis project exploring Olympic medal records across
different disciplines, countries, genders, and athlete/team categories.

## 📌 Project Overview

This project analyzes Olympic medal data from Beijing 2022 and Tokyo 2020
using Microsoft Excel. The workbook includes raw medal records, PivotTables,
and visual summaries to identify patterns and trends in Olympic performance.

## 📂 Dataset

The dataset contains information about:

- Olympic disciplines and events
- Games and participating countries
- Gender categories
- Athlete and team classifications
- Medal types: Gold, Silver, and Bronze
- Country codes and athlete information

The dataset contains 1,407 medal records.

## 📊 Analysis & Visualizations

The project explores:

- Medal distribution by gender
- Discipline-wise medal distribution
- Athlete versus team medal categories
- Country-wise medal counts at Tokyo 2020
- India's Olympic performance at Tokyo 2020

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Data Analysis
- Data Visualization

## 🎯 Key Findings

- Men accounted for the highest number of medals in the dataset.
- Athletics, Swimming, and Wrestling were among the most represented
  disciplines.
- The United States, China, and Japan recorded the highest medal totals
  among the listed countries in the Tokyo 2020 analysis.

## 📁 Workbook Structure

- `olympic_medals` – Raw Olympic medal records and India's performance data.
- `Data_Visualization` – PivotTable summaries and analysis.

## 🚀 Purpose

This project was created to practice data organization, analysis, and
visualization using Microsoft Excel and to develop practical data analysis
skills.
